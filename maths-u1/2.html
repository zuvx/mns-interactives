A new machine

The machine that wraps sweets in twos

This machine wraps sweets in pairs. Sometimes every sweet finds a partner. Sometimes one is left on its own.

Do not guess from the last digit yet. Run the machine and look at what happens. By the end you will work out the rule for yourself.
Station 1 · Run the machine

Pair them up and see

Press Pair them up. Watch whether every sweet finds a partner, then decide.

Station 2 · What did you notice?

Now find the rule yourself

You have run the machine six times. Look back at which numbers paired up perfectly.

Say it out loud: an odd number is an even number add 1. That is why there is always exactly one left over, never two.
Station 3 · The sorting board

Sort the batch numbers

Every batch has a number. Sort them into the two columns. Read the headings carefully — the second one says not even.
